# RecoLens 7 — 점수로 바뀌는 추천

영화 5편을 1~5점으로 평가 → 네 추천 목록에 각 1~5점 → 알고리즘 공개 → 내 점수를 반영한 추천 6편.

## 실행 / 배포

- `index.html`, `styles.css`, `data.js`, `metadata.js`, `engine.js`, `app.js`, `sw.js`, `.nojekyll`은 같은 폴더에 둡니다.
- GitHub Pages의 기존 `index.html`이 있는 위치에 이 파일들을 함께 교체합니다. ZIP 자체를 업로드하는 방식이 아닙니다.
- 별도 서버나 API 키, 계정 없이 추천을 계산합니다. 개발 시 `python -m http.server 8000`으로 로컬 서버를 사용할 수 있습니다.
- `python scripts/build_standalone.py`로 실행 코드와 데이터를 모두 포함한 HTML을 생성할 수 있습니다. 단일 파일은 별도 서비스 워커를 등록하지 않습니다.
- 정적 앱 캐시 버전은 7.0.0입니다. 외부 영화 포스터와 출연진은 캐시되는 필수 앱 데이터가 아닙니다.

## 점수 입력

영화를 누르면 그 영화만 평가하는 작은 창이 열립니다. 1~5점을 드래그하거나 숫자를 눌러 선택한 뒤 **저장**합니다. 아직 저장하지 않은 초기 3점은 추천에 들어가지 않습니다. 평가한 카드에는 점수가 표시됩니다. 정확히 5편을 평가하면 다음 단계로 넘어갑니다. 새 영화로 교체할 때도 저장 전까지 이전 평가는 유지됩니다.

추천 화면에는 영화 6편과 목록 전체를 평가하는 슬라이더 하나만 있습니다. 4개의 목록을 모두 평가해야 결과를 공개합니다. 목록을 구경하는 것만으로 기본값 3점이 등록되지 않습니다. 동일 최고점은 먼저 알아볼 목록을 직접 고르게 하며, 어떤 것을 선택해도 최종 계산에는 네 점수가 모두 반영됩니다.

드래그 외에도 숫자 클릭, 방향키, Home/End를 지원합니다. 이동 중에 슬라이더나 영화 포스터를 다시 생성하지 않습니다. 조작 영역을 가리던 하단 버튼은 본문 흐름 안으로 옮겼습니다.

## 추천에 실제로 반영되는 내용

- 영화: `점수 - 3`을 콘텐츠 특징 및 아이템 협업 연결에 곱합니다. 1~2점은 부정, 3점은 중립, 4~5점은 긍정입니다.
- 목록: 높은 점수를 준 추천 방식의 혼합 비중이 커집니다. 네 기본 목록은 평가 중 고정됩니다. 마지막에 **내 점수로 다시 추천**을 눌러 혼합 추천을 만듭니다.
- 한 목록의 점수를 그 안의 영화 각각의 점수로 간주하지 않습니다.
- 피드백은 로컬 가중 혼합 규칙입니다. MovieLens의 사용자 평점 전체를 재학습하거나 정확도 향상을 검증한 것은 아닙니다.
- 같은 점수에는 같은 비중을 주며, 모두 중립인 영화 입력도 강제로 좋아요로 바꾸지 않습니다.
- 점수가 달라져도 순위 상위 영화가 동일할 수 있습니다. 서로 다른 두 방식의 순위가 완전히 같으면 해당 방식들의 비중 교환도 결과를 바꾸지 않을 수 있습니다.

자세한 식: `docs/ALGORITHM.md`. 실제 실행한 검증과 한계: `docs/TEST_REPORT.md`.

## 저장과 데이터

영화/목록 점수는 `recolens-v7-session`에만 저장합니다. 이름·학번·계정·설문 응답을 서버로 수집하지 않습니다. 저장이 차단된 환경에서도 현재 세션은 작동하지만 새로 열었을 때 이어지지는 않습니다. v6의 좋아요는 명시적인 1~5점 평가가 아니므로 자동으로 5점으로 변환하지 않습니다. 이번 버전에서 다시 평가합니다.

외부 포스터/메타데이터 요청에는 영화 ID, 제목·연도 및 접속 정보가 제공처에 전달될 수 있습니다. 점수 자체는 요청에 포함하지 않습니다. 외부 연결은 이용 안내에서 끌 수 있습니다. 포스터 연결 실패 시 제목 카드와 네이버 영화 검색을 제공합니다. 모든 포스터가 표시된다고 보장하지 않습니다.

영화 데이터는 기존 MovieLens 2018 기반 1,800편을 유지했습니다. 원본 이용 조건은 `MOVIELENS_LICENSE_AND_README.txt`를 확인하세요. 실제 흥행 순위나 모든 국내 관객의 취향을 대표하지 않습니다.

## 검사 재실행

```sh
node tests/engine.test.js
python scripts/build_standalone.py
python tests/browser.test.py inputs
python tests/browser.test.py edge
python tests/browser.test.py responsive
```

브라우저 테스트는 Python Playwright와 Chromium이 필요합니다. 실행 파일은 `CHROMIUM_PATH` 환경변수로 지정할 수 있습니다. 미지정 시 시스템 Chromium을 사용합니다. 현재 테스트 러너에서는 HTTP/file 탐색이 차단되어, 생성한 단일 파일을 `set_content`로 렌더링합니다. 실제 GitHub 배포 성공이나 물리적 iPhone에서의 검증을 의미하지 않습니다.
